# Run GRV6Spikes on the iPad (no Mac needed)
1. Install **Swift Playgrounds** (free, App Store) on the iPad mini 6.
2. Get `GRV6Spikes.swiftpm.zip` onto the iPad (Claude app download, AirDrop, or iCloud Drive).
3. In Files, tap the zip to unzip. You get `GRV6Spikes.swiftpm` (shows as a Playgrounds app).
4. Tap it to open in Swift Playgrounds, then press Run (▶). First build takes ~1 min.
5. Optional: in Playgrounds, App Settings > "Install on This iPad" puts it on the Home Screen.
6. Plug the GRV6 (powered from its adapter) into the hub, follow Spikes/README.md.
